# Server Waypoint fold (package `serverwaypoint`)

Idea and command shape follow **Server Waypoint** 4.0.1 by 2676959 (https://github.com/2676959/server_waypoint).
Licence: MIT, verified from the repository's LICENSE file ("MIT License, Copyright (c) 2026 2676959"). Its Material Design icons (Apache-2.0, THIRD_PARTY_NOTICES) are client UI assets and are NOT used.

Changes: rewritten as a small server-only package for NeoForge 26.1.2. Kept: named shared lists of named waypoints stored with the world; `/wp list`, `add`, `remove`, `addlist`, `removelist`, `nav`, `tp`; navigation on the action bar. Left out: client mod, waypoint manager GUI, map mod sync (Xaero, VoxelMap), colours/icons, Velocity cross-server. No upstream art. No turn-based mechanics.
