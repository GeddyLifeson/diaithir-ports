Untamed Wilds 3.0.1-diaithir.2 (GPL-3.0-only). Original by RayTrace082 and Raguto, https://github.com/RayTrace082/untamedwilds.
The jar is the Diaithir 26.1.2 port of 3.0.1 (full source: https://github.com/GeddyLifeson/diaithir-ports/tree/untamedwilds, with the 64x creature art) plus one change set, null-safe-species-data.patch.
Cause: species data (ComplexMob.ENTITY_DATA_HASH) is only loaded on the logical server. A client on a dedicated server gets null from getEntityData(), so any client-side call that dereferenced it threw. A real client log (2026-10-24 22:10) shows the baleen whale constructor failing in ComplexMob.getModelScale, which disconnects the player ("Failed to handle packet ClientboundBundlePacket").
Change: ComplexMob.getModelScale returns 1.0 when there is no data, and every getFlags lookup in the entity classes goes through the new ComplexMob.safeFlags, which returns 0 when there is no data. This covers snake, anaconda, newt, boar, baleen whale, bear, big cat (replacing the diaithir.1 getTexture patch) and shark. Server behaviour is unchanged because the data exists there.
Built by compiling the changed classes (ComplexMob, EntitySnake, EntityAnaconda, EntityNewt, EntityBoar, EntityBaleenWhale, EntityBear, EntityBigCat, EntityShark) against the diaithir.1 jar and replacing them in it; mods.toml version is 3.0.1-diaithir.2, mod id unchanged.
To get the complete corresponding source, open an issue at https://github.com/GeddyLifeson/diaithir-ports/issues.
