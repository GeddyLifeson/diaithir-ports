# diaithir-worldgen-structures
Data-only NeoForge 26.1.2 module. Clean-room: 186 original structures designed from public behaviour descriptions of 40 all-rights-reserved or unknown-licence structure mods; no source code, templates or assets used.
- `tools/gen.py` turns `blueprints/*.json` (block-grid designs) plus `tools/specs.json` into `src/main/resources` (templates, jigsaw structures, structure sets, loot tables).
- Integration (INTEGRATION.md): biome tags use vanilla/`c:` tags, per-Age structure tags (`age_i`..), `diaithir_events.json` (calendar year, disaster, war, raid; ruin states), Codex entries and a quest per structure, `migration.json` maps old mod prefixes to new ids.
- TODO: upgrade rules (no working blocks here), cross-mod recipes (none), stronger biome tag coverage, client world-join and locate test.
- Build jar: `cd src/main/resources && zip -r ../../../diaithir-worldgen-structures-1.0.0.jar .`

## Panscriptum sites (tools/lib_sites.py)
All 44,015 STRUCTURE entries of the Panscriptum (library-content/content.sqlite, text from codex-store/library.sqlite) are generated as data: one plaque template per entry (a lectern holding a written book with the entry's own summary verbatim, author "Panscriptum"), 12 site classes picked by keywords in the entry text, shared class buildings per soil and size, 3,749 jigsaw structures (planet x class x Age band), one structure set per planet, biome tag `diaithir_worldgen:lib/<planet>` and Age tags `lib_age_N` (planet opens_age + band). `library_sites.tsv` maps entry id to planet, class, band and template. Regenerate: `python3 -I tools/lib_sites.py` (about 25 s).
- Terra (`diaithir`) uses `#minecraft:is_overworld`. Every other planet's tag points at the optional biome tag `#diaithir_planets:<planet>`, which the biomes-dims module must fill with that planet's own biomes; a structure set cannot be limited to a dimension any other way, so planets without their own biomes get no sites yet.
- Checked: vanilla 26.1.2 server loads the pack with no errors, `/locate` finds Terra sites of all 12 classes, templates load and the lectern book reads back. Not checked: planet dimensions in game, Ember/Hollow/Quiet heights, NeoForge full-pack boot.
- `pack.mcmeta` here uses `pack_format` only; a plain datapack folder on 26.1 needs `min_format`/`max_format` (101).
- Terra (407 entries): every entry has its own building (`structure/lib/diaithir/b/`), shaped from its text (pyramid, stone ring, mound, cave, dome, gate, walled town, towers, harbour, bridge, rows of figures; otherwise the class building) and made of the materials the text names (brick, clay, timber, sand, copper, glass and steel...). Size from words like huge/small. Chests use `lib/loot/<class>` tables; tomb, delve, fortress and ruin sites carry a vanilla mob spawner as a placeholder until the mobs lane's entities exist. NPC hooks are not placed yet.
- NPC hook: where an NPC of the same planet is named in a site's text (3,894 sites), the plaque has a barrel beside the lectern with CustomName `lib_npc:<call number>:<count>`; `library_sites_npc.tsv` lists the same pairs. The NPC lane turns the barrel into that person on first load.
- Checked with the planet biome tags of diaithir-ports #145 loaded: `/locate` finds Ashestith sites inside `diaithir_planets:ashestith` and none in the overworld.
- Mob spawners name body-plan entities of diaithir-fauna (`diaithirfauna:<plan>`, PR #154): tomb scorpion, delve giant_arthropod, fortress theropod, ruin lizard, harbor crocodilian. In a planet dimension the fauna mod picks a hostile Library creature of that plan; elsewhere it uses the plan's normal species. Not tested in a live world.
