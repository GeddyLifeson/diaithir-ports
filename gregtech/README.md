# GregTech CEu Modern (unofficial 26.1.2 port)

This is an unofficial NeoForge 26.1.2 port of GregTech CEu Modern, made for Marlon's Diaithir pack. It is not made, endorsed or supported by the original authors. Please do not report bugs from this port to them.

Original mod: https://github.com/GregTechCEu/GregTech-Modern (1.21.1 branch, version 8.0.0).
Original authors: the GregTech CEu team and contributors.

Licence: LGPL-3.0 (see `LICENSE`). The source of this port is this directory. The original art, sounds and lang files are the original authors' work under the same licence terms as the upstream repository.

The build bundles a port of Registrate by tterrag and contributors, under MPL-2.0.

The mod id is `gtceu`. What was changed, stubbed or removed is listed in `PORT_NOTES.md`. The upstream README is kept as `README.upstream.md`.

Build: `./gradlew build` with JDK 25. Part of the Diaithir modpack for NeoForge 26.1.2.
