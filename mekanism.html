This is an unofficial NeoForge 26.1.2 port of Mekanism by Aidan C. Brady and the Mekanism team (Thommy101, Thiakil, pupnewfster, dizzyd). The original authors did not make it and do not support it, so please report problems with this build at https://github.com/GeddyLifeson/diaithir-ports/issues and not to them.

What changed

Built unmodified from Mekanism's own unreleased 26.1 branch. The API is merged into the main jar, as official releases do.
