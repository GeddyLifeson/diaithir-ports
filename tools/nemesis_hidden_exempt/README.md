diaithir-nemesis has no source in any repo, so the jar is patched. `HiddenExempt` reads the optional `config/diaithirnemesis_hidden.json` (`{"exempt":["Uber_Byte"]}`, names or UUIDs; offline-mode UUIDs are derived from names). `Patch.java` (ASM) inserts a call in `DiaithirNemesis.onRespawn` so listed accounts skip the infinite Weakness (Shaken). No default file, not in the config menu. Build: javac HiddenExempt with --release 21, run Patch on DiaithirNemesis.class (read it as version 68, write back 69 if ASM < 9.8), put both classes in the jar.
