# Row 8: creature drop tags and Age-gated spawns

Generated by `tools/crossmod_row8.py` (re-run with `--jar` for each mod jar, `--tech-ages content/tech_ages.json`). Install: copy `data/` into `kubejs/data/` and `server_scripts/crossmod/` into `kubejs/server_scripts/`.

## Drops (survey of 117 entity loot tables: Ice and Fire 38, Untamed Wilds 29, Vampirism 54, read from the jars)
- Every dropped scale, feather, egg, leather and bone item is now in a shared tag. `data/c/tags/item/{scales,leathers,leather,feathers,eggs}.json` (all entries `required:false`).
  - c:scales: IaF `dragonscales_*` (12), `sea_serpent_scales_*` (7), `shiny_scales`. No other mod drops a scale.
  - c:leathers / c:leather: IaF troll leathers, plus `#c:leather` (Untamed Wilds' bear/big-cat hides already sit there). Vanilla leather is already tagged by NeoForge.
  - c:feathers: amphithere and stymphalian feathers. c:eggs: 12 dragon eggs, 2 death worm eggs, 12 Untamed Wilds eggs.
  - c:bones: IaF already tags dragonbone/witherbone; nothing to add.
- Gaps filled by `row8_drops.js` (drop only if absent): bones for hydra, sea serpent, gorgon, siren, troll, vampires, hunters; eggs (25%) for diaithir-fauna galliform/waterfowl/ratite/pigeon/seabird.
- Not filled: no scale for reptiles and fish in diaithir-fauna or Untamed Wilds (no scale item exists; inventing one needs a Java item and a Library entry). Vampirism `converted_*` have empty tables (they inherit nothing; left alone). Dragon eggs in c:eggs means egg recipes accept them; drop the 12 `dragonegg_*` lines in `tools/crossmod_row8.py` if that is unwanted.

## Spawn gating (`row8_spawn_age.js`, same pattern as earth_timeline/extinctions.js)
Natural spawns only (command, egg, spawner, breeding exempt). Age from diaithir_ages `AgesSavedData`, else score `#age` in `diaithirfauna_age`.

| Entity | Min Age |
|---|---|
| untamedwilds:* , diaithirfauna:* (living fauna; extinctions.js handles the dates) | I |
| iceandfire: hippogryph, hippocampus, pixie, amphithere, cockatrice, stymphalian_bird, siren, sea_serpent, deathworm, cyclops, troll, gorgon, hydra, ghost | III |
| iceandfire: fire_dragon, ice_dragon, dread_* | IV |
| iceandfire: lightning_dragon | V |
| vampirism: hunter, vampire, blinding_bat, ghost | IV |
| vampirism: advanced_hunter, advanced_vampire, vampire_baron, dracula | V |
| mutantmonsters:* | V |
| aether_ii:* | no Age gate; cancelled outside dimensions whose id starts `aether_ii:` |

The Age numbers are my design calls, not from a spec. Full machine table: `data/diaithirfauna/spawn_ages.json`.

## Not verified
- Nothing was run in game; scripts only syntax-checked with node. The KubeJS 8 `EntityEvents.checkSpawn`/`EntityJoinLevelEvent` calls are copied from extinctions.js, the scoreboard fallback API is untested.
- Aether II and Mutant Monsters jars are not in the repo or builds (only `.pw.toml`): their loot was not surveyed, entity ids are unverified (namespace rules only), and the Aether dimension id prefix `aether_ii:` is assumed.
- Ice and Fire has no data-driven spawn list found (spawns come from Java config), so gating cancels at join, which wastes spawn attempts but is safe.
- `tech_ages.json` has no entry for iceandfire, untamedwilds, vampirism, mutantmonsters or diaithirfauna (items default to Age I); Age-gating the items is a separate change.
- Loot tables checked are the jar defaults; IaF dragon/sea serpent drops also come from Java loot functions (`DragonLootFunction`), not scanned.
