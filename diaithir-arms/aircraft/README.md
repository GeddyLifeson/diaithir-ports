# Aircraft roster (Immersive Vehicles pack, inside diaithir-arms)

`ROSTER.csv`: one iconic mass-produced design per row, no variants (same rule as the guns). 69 rows: kites, balloons, gliders and airships (Ages III to VI, the primitive predecessors), pioneer, WWI, interwar, WWII, jet, modern airliners, transports, trainers, utility, seaplanes, drone, 5 helicopters. `source` is the Wikipedia page for each row; `first_flight_year` drives Age gating (III to V for the primitive craft, VI up to 1945, VII after; the tech-by-age doc puts aircraft in VI).

Status: roster only. Mod-first check: Immersive Aircraft (tech-batch-a) only covers a few generic craft, so the named designs are built clean-room as `assets/diaithiraircraft/` in this jar, same generator pattern as `tools/gen_tank.py`. Not started: models, textures, IV defs, Diaithiris names, library/codex. Fuel comes from the shared fuel system (cars thread), assembly from the shared assembly yard (airframe/hangar yard requested), guns hook into diaithir-firearms. Specs (mass kg, speed m/s, range m) to be filled from each source page, SI only.

## Generator (first batch)
`tools/gen_aircraft.py <module dir>` writes the IV pack `assets/diaithiraircraft/` (parametric box models, flat textures, engine part and vehicle JSON) for 11 designs so far: Wright Flyer, Blériot XI, Sopwith Camel, Spitfire, P-51, DC-3, B-17, Me 262, Cessna 172, Boeing 747, UH-1. It also writes `aircraft/aircraft_manifest.json` and `age_gates_aircraft.json`. Spans, lengths, masses and fuel are rounded from each source page (approximate). Engines use fuel type `avgas` (maps to the shared fuel API). Checked: all 22 JSON files parse; the 11 engine parts load with IV's `JSONPart` class under plain Gson. Vehicle defs need IV's own Point3D adapter, so they were checked only for structure (the tank pack behaves the same under plain Gson). Not tested: IV loading, flight, models are crude silhouettes, no propellers, undercarriage, weapons or yard part catalog yet, helicopters and balloons need rotor/blimp defs. The other 58 rows still need specs.
