# Diaithir Look-At

Client-only box under the top of the screen naming the block or creature under the crosshair, its mod, and a creature's health (stands in for Jade, CC BY-NC-SA). MIT. Clean-room.

Compiles on JDK 25; a server with it loads (no entry point on the server). The drawn box needs a client: check at the first full-pack join that it shows and does not clash with a kept HUD.
