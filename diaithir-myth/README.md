# Diaithir Myth Beasts

Eighteen mythic creatures for the Diaithir game pack (NeoForge 26.1.2, mod id `diaithir_myth`).

Creature stats, behaviours and presets are adapted from **Greek Fantasy** by **skyjay1**
(https://github.com/skyjay1/GreekFantasy, GPLv3). This mod is GPLv3 as well.
No upstream model, texture, sound or language file is used: all geometry, skins, egg icons and names are new,
and every creature carries a coined Diaithiris name.

## What is in it

* Beast, flyer and avatar presets. Beasts walk, fight or flee. Flyers hover and flee. Avatars are two-phase
  bosses with a boss bar: below 50% health they speed up (+35%), hit harder (+20%) and gain one extra attack
  (ground slam, charge, web snare or venom cloud, depending on the creature).
* Courts: hellenic, minoan, italic, anatolian, canaanite and nilotic. Living-tradition courts get nothing here.
  Creatures that already exist in the pack (marked `iceandfire:*` in the creature table) are skipped.
* Spawn eggs, loot tables, English lang and one biome modifier per creature (low weights). Each creature spawns only in
  the biomes of its habitat: `data/diaithir_myth/tags/worldgen/biome/habitat/<habitat>.json` (woods, mountains, hills,
  coast and sea, desert, reeds and so on; the `c:` convention tags are optional). A pack can override a habitat tag.
* Court region and Age gate (see below).
* `data/diaithir_myth/myth/creatures.json` is the single source of the creature table (stats, size, court, sounds);
  `data/diaithir_myth/myth/courts.json` lists each creature's court.

## Where and when they spawn

The world is Earth at 1:5 scale generated by Tellus, so each creature's natural spawns follow its court's real region.
`data/diaithir_myth/spawn_regions/<creature>.json` holds `min_age` (and optionally `max_age`) and lat/lon `boxes`
(a box with lon min above lon max wraps the antimeridian; an empty list means never). The files are datapack data and
reload with `/reload`; they are written by `tools/gen_spawns.py` from the court `region` text in `courts.json`.

* Only NATURAL and CHUNK_GENERATION spawns are gated (the spawn placement check and a `FinalizeSpawnEvent` guard).
  `/summon`, spawn eggs, spawners and saved mobs are never touched.
* Block to lat/lon uses the Tellus projection (Web Mercator, `blocksPerDegree = 111319.49166666667 / world_scale`,
  longitude wrapped at the world edge). The scale is read from the Tellus Earth chunk generator by reflection
  (default 5). In any world without the Tellus Earth generator the region test is skipped, so flat and vanilla worlds
  behave as before.
* Age: soft dependency on `diaithir_ages`, read by reflection (`AgesSavedData.get(server).world.age`, ids `TELLING`,
  `I` to `VII`, cached ten seconds). If the mod is absent or unreadable the world counts as Age III open. A creature
  needs `min_age` <= the current Age, so Age II beasts appear from Age II and the Age IV gate guardian only once the world
  reaches Age IV (never, without `diaithir_ages`).
* The `diaithir-compat` mod has a similar `earth_ranges` gate without an Age; this mod does not need it.

Untested in game: spawning inside a real Tellus world (the unit tests cover the conversion and boxes; the boot test runs
on a vanilla world, where the region test is off), and the Age lookup against the real `diaithir_ages` jar.

## Building

    python3 tools/gen_myth.py   # regenerates data and art (needs Pillow and numpy; reads the creature table)
    python3 tools/gen_spawns.py # spawn regions, habitat tags and spawn modifiers only (no Pillow needed)
    ./gradlew build   # also runs the JUnit tests (needs network for the test libraries the first time)

JDK 25 is required.
