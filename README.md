# Untamed Wilds (unofficial 26.1.2 port)
___

Unofficial NeoForge 26.1.2 port of Untamed Wilds, used by the Diaithir modpack. Report problems with this build in this repository, not to the original authors.

- Original mod by RayTrace082: https://github.com/RayTrace082/untamedwilds (GPL-3.0)
- NeoForge 1.21.1 port by Raguto, which this port is based on: https://github.com/Raguto/UntamedWilds-1.21.1 (GPL-3.0)
- This port is licensed GPL-3.0-only, see `LICENSE`.
- Citadel is no longer a dependency. The few Citadel classes the mod used (animation and model helpers, by Alexthe666, iLexiconn and gegy1000) are vendored under `untamedwilds.citadel` from the 26.1.2 port in [Alex's Mobs Continued](https://github.com/Codx-org/AlexsMobsContinued) (GPL-3.0-only), with their licence headers kept.
- Villager trades (Fisherman, Butcher) are not ported yet, as they are data-driven in 26.1.
