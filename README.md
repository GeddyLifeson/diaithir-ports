# SecurityCraft (Diaithir patched build)

This is a patched build of the official 26.1.2 release of [SecurityCraft](https://www.curseforge.com/minecraft/mc-mods/security-craft) by Geforce, bl4ckscor3, Redstone_Dubstep and ChainmailPickaxe. The original authors did not make it and do not support it, so please report problems with this build at https://github.com/GeddyLifeson/diaithir-ports/issues and not to them.

## What changed

The official 26.1.2 release with one mixin removed (`mines.OldMinecartBehaviorMixin`, rail mines under minecarts), because it clashes with Railcraft Reborn's minecart mixin. Use the official release unless you run both mods.
