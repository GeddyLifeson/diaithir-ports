## vehicletuning
Registry-free tuning and compat layer for third-party vehicles and aircraft. VehicleTuning holds constants (speed, fuel burn, damage and repair multipliers, clamps) and a Profile record with a clamping factory. VehicleCompat reports whether an external vehicle or aircraft mod is loaded, by checking known mod ids through ModList, and exposes the active profile (default, or a boosted profile when a vehicle mod is present). The feature has no registries and no entities. It only registers a tiny server-start hook that logs which vehicle mods were found. Migration: {}

## portallinkfix
When a player is about to be teleported through a Nether portal, the destination is checked server-side. The game normally searches for an existing portal near the scaled target coordinates; on busy multiplayer servers the nearest portal may belong to a far-off unrelated network, or the scaled target may land inside a different dimension's world border margin. This feature clamps the scaled destination position inside the destination world border and prefers an existing portal within 16 blocks of the exact scaled spot (via the POI manager) before vanilla's wider search picks a distant one. The player is informed on the overlay when their destination was adjusted. Migration: none.

## aircrafttuning
Registry-free compat layer for aircraft addons. AircraftTuningFeature.register wires a server tick that, once at server start, logs which optional mods (immersive_aircraft, create) are present via ModList. Tuning is a constants class: per-type multipliers for speed, lift, fuel burn and a Create stress-unit cost per second for rotor-driven types, plus a clamp helper and a pure function scaling a base value by type. A small lookup resolves a type id string (path only, e.g. 'gyrodyne') to its tuning with a neutral default. Other modules call AircraftTuning.get(id).speed() etc. No entities, blocks or items are added. Migration: {}.

## worldqol
WorldQol bundles small server-side quality-of-life tweaks. 1) Crop trampling: farmland is never turned to dirt by entities falling on it, except for the player's own sneak-less jumps being harmless too. 2) Sleep comfort: waking in a bed grants a short Regeneration effect and a overlay message. 3) Sapling rescue: when a sapling item entity expires (despawns) on a grass or dirt block, it is planted there instead of being lost. 4) Sneaking right-click on a fully grown crop with an empty hand harvests and replants it, giving normal loot minus one seed. No toggles. Migration: none.

## itemmagnets
Two magnet items: Iron Magnet (radius 6, pull 0.12) and Gold Magnet (radius 12, pull 0.2). While a magnet is in a player's main inventory, hotbar or offhand, each server tick that player attracts nearby dropped items: items with no pickup delay left and not recently thrown by that player glide toward the player's feet. Sneaking suspends attraction. Items closer than 0.6 blocks are left to vanilla pickup. Strongest magnet in inventory wins; only one scan per player per tick. Both magnets are non-stackable and appear in the Tools creative tab. Recipes: iron magnet from 2 iron ingots, 1 redstone, 1 lapis in a U shape; gold magnet from iron magnet plus 4 gold ingots plus 4 redstone. Migration: none.

## utilityblocks
Five utility blocks. Angel Block: item that places a stone-like block in mid air up to 5 blocks along the look direction when used and not aimed at a block. Sky Sand: a gravity-free sand that never falls but is otherwise brittle like sand. Redstone Clock: emits a redstone pulse for 2 ticks every 20 ticks (1 second) on its own, self-scheduling. Fluid Hopper: placed with its funnel facing down, each 8 ticks it removes a source fluid block directly above it, clearing lakes and lava pools, and drops nothing. Quality-of-life: a Lamp Block that emits light level 15 and never needs power. Migration: none.

## veinbreaker
While a player holds the break key sneaking (crouched) and mines an ore block in survival with a tool that can harvest it, all connected blocks of the same type are broken too, flood-filled through the 26 neighbouring positions, capped at 64 blocks and radius 12 from the origin. Each extra block drops its normal loot at the player and costs the tool one durability point; the chain stops if the tool would break. Each extra block adds 0.05 exhaustion. Only blocks in the c:ores tag trigger it. Creative players and non-sneaking players are unaffected. Migration: none.

## skilltrees
Four skills: mining, combat, farming, exploring. Players earn XP by breaking ores/stone (mining), killing mobs (combat), harvesting mature crops (farming), and traveling distance (exploring, sampled once per second). XP is stored per player in a persistent attachment (copied on death). Level thresholds grow linearly: level n needs 20*n XP. Max level 20. Each level grants a tiny permanent bonus via attribute modifiers: mining +2% block break speed per level, combat +0.1 attack damage per level, farming +0.5 max health per 5 levels, exploring +0.1% movement speed per level. Level-up shows an overlay message and plays a sound. Command /skills shows levels; /skills reset <player> (op) clears. Migration map: none.

## gemrings
Three gem items (ruby, sapphire, topaz) drop as bonus loot when ore blocks are mined: probability 8% per ore break, gem chosen uniformly. Each gem crafts with 4 gold ingots into a ring (shapeless 4 ingots + gem, shaped as ring pattern). Rings are items that grant a permanent-while-carried status effect: ruby ring gives Strength I, sapphire ring gives Water Breathing, topaz ring gives Haste I. Effects are refreshed every 40 ticks on the server for players holding the ring anywhere in their inventory (first matching ring per type counts once; effects use ambient, no particles, 100-tick duration). Rings stack to 1. Gems and rings appear in the Ingredients and Tools creative tabs respectively. Migration: none.

## mobbraintuning
Reduces mob AI cost and adds a command to switch off chosen behaviours. Mobs more than 48 blocks from every player in their level are marked no-AI (frozen, not removed) and unfrozen when a player comes within 40 blocks; only mobs frozen by this system are ever unfrozen, tracked via a persistent entity tag. Checks run per mob every 20 ticks, staggered by entity id. Pets, boss mobs, persistent or named mobs, and passengers are never frozen. Command /mobbrain disable|enable <behaviour>, op level 2, with behaviours: panic, wander, look_around, avoid_players, mob_attacks. Disabled behaviours are removed from the goal selectors of mobs as they join a level, but mobs already loaded keep goals until reloaded. Disabled set is held in memory per server session. Migration: none.

## structurecompass
Wayfinder Compass: a craftable item (compass surrounded by gold ingots plus an eye of ender at the centre ring is overkill, so: 4 gold ingots, 1 compass, 4 redstone). Right click in a ServerLevel searches for the nearest unseen structure of the next type in a fixed cycle (village, stronghold, mineshaft, shipwreck, ruined portal, pillager outpost, ancient city, trial chambers) using the chunk generator's structure search within 100 chunks. Sneak right click cycles the target type instead. The found position is stored as a custom data tag on the stack; each server tick a held compass gets an actionbar line with target name, distance and a cardinal direction arrow. Using the item has a 40 tick cooldown. Migration: none, new ids diaithirworldsys:wayfinder_compass.

## packversioncheck
On the server status ping, the server advertises a pack version string (a constant in PackVersionConstants, appended to the version name shown in the server list). On the server login side, the client hello is not touched; instead players are compared after joining: each client sends its pack version via a registered optional custom payload on the configuration/play channel. If the payload is absent or differs from the server pack version, the player is disconnected with a message stating both versions. Clients that lack the mod entirely are accepted only when the constant ALLOW_UNVERSIONED is true. Migration: none (new feature).

## pocketbench
Adds a Pocket Bench item (craftable from a crafting table over a stick). Using it in the air or on any block opens a portable crafting grid for the player, valid wherever they stand, without needing a table nearby. Sneak-using on a block still lets the block interact normally (chests, doors). Item has a 1.5 second use cooldown to avoid spam. Recipe: crafting table above stick, shapeless. Migration: none (new content).

## gridkeys
Three server-handled actions for the crafting grid a player has open (crafting table, inventory 2x2, or any menu exposing a CraftingContainer). Rotate turns the grid contents 90 degrees clockwise (square grids only). Balance evenly redistributes each stack type across the occupied slots of that type, keeping total counts. Clear moves all grid items back to the player inventory, dropping any overflow. Clients bind three unbound-by-default keys (rotate, balance, clear) in a controls category and send a small payload carrying the action id; the server validates the open menu and acts. migration: none.

## calmpiglins
Piglins stay calm while a player barters with them. When a player right-clicks a piglin holding gold (any item the piglin accepts as barter currency), that player is registered as a recent trader for 40 ticks. While registered, any attempt by that piglin to become angry at that player is cancelled and any anger target already set to that player is cleared. Bartering by dropping gold near a piglin is covered by remembering the dropper for the same window and checking nearby piglins. Registrations expire automatically. No effect on other aggravating actions such as attacking a piglin or opening chests, once the grace window has ended. Migration: none.

## villagercare
Villager quality-of-life, server side only. (1) Trade stability: villagers whose job-site block is lost never lose their level-locked trades; a villager that has already been traded with keeps its profession even when its workstation vanishes. (2) Trade refresh: each in-game dawn, every loaded villager with a profession has all of its trades restocked once (uses reset to zero), regardless of work-site presence. (3) Panic reduction: villagers ignore hostile mob panic unless the mob is within 6 blocks, by clearing their panic brain memory when no hostile is that close. (4) Fair prices: negative reputation penalties capped so a price never exceeds 1.5 times base. No migrations. migration: none.

## admincommands
Server utility commands registered via RegisterCommandsEvent. Admin (permission level 2) commands: /home-style transport is player-facing, the rest admin. Player commands: /sethome, /home, /spawn, /back, /tpa <player>, /tpaccept, /tpdeny. Admin commands: /heal [player], /feed [player], /fly [player] (toggles mayfly), /vanishlite [player] (toggles invisibility effect), /tphere <player>. Homes and last locations are stored in memory per player UUID (cleared on restart). Teleport requests expire after 60 seconds. /back returns to the position before the last teleport or death. Migration: none.

## questbook
Server-side quest progression. A fixed list of quests is defined in code. Each quest has an id, a task type (KILL entity type, MINE block, COLLECT item, CRAFT item), a target id, an amount, optional prerequisite quest id and a reward item stack. Players belong to at most one team (created and joined via /quests team create|join|leave); progress is stored per team, or per player when teamless, in a SavedData on the overworld. Matching game events add progress to every unlocked, unfinished quest. Finishing a quest grants the reward to the finishing player and notifies all online team members. Commands: /quests list, /quests progress. Migration: none.

## rankperms
Operators manage named ranks through /rank. Each rank has a priority, a chat prefix colour, a prefix text, and a set of permission nodes. Players can hold one rank, stored in server-level saved data. The player's display name in chat, tab list and above the head is formatted with the rank prefix and colour. A rank grants permission nodes; other code can query RankPerms.has(player, node). Wildcard node 'a.b.*' matches any child. Commands: /rank create <name> <priority>, /rank delete, /rank prefix <name> <text>, /rank color <name> <colour>, /rank grant <name> <node>, /rank revoke, /rank set <player> <name>, /rank clear <player>, /rank list. Data persists across restarts. Migration: none.

## villageguards
Adds a Village Guard: a sturdy, iron-armed humanoid that spawns in villages and defends them. Registered as an entity type with attributes (30 health, 0.35 speed, 6 attack damage, 32 follow range). Goals: melee attack, move through village, wander, look at players, hurt-by retaliation, and active targeting of Monster mobs, raiders and pillagers (not creepers fleeing logic, just generic Monster) but never players or villagers. Guards spawn naturally: when a villager first joins a server level with no guard within 48 blocks, one guard spawns beside it, rate-limited to one per 48-block area per 5 minutes. Guards despawn never when persistent. A spawn egg item is added to the spawn eggs creative tab. Migration: none (new content).
