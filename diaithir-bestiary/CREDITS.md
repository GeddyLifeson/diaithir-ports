# Credits

- GeckoLib (MIT, https://github.com/bernie-g/geckolib): models, animation and rendering; a runtime dependency, not bundled.
- The idea of creatures defined in data rather than code comes from EntityJS (GPL-3.0). Ice and Fire (LGPL-3.0) is the model for tamed, rideable dragons. No code from either was copied, so this mod stays MIT.
- Ridden flight follows the shape of vanilla Minecraft's rideable flyer (look to climb or dive, jump to rise); the stalker's gaze test uses vanilla `LivingEntity.isLookingAtMe`, the same test endermen use.
- Example models, animations and textures were made for this mod by `tools/gen_examples.py`.
