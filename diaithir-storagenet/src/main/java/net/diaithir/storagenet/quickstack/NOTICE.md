# Quick stack (from Terrastorage)

Ported from Terrastorage 1.3.2 by Tim (TimVincii), MIT, https://github.com/TimVincii/Terrastorage (branch 26.1-to-26.1.2), licence text in LICENSE-Terrastorage.

Kept: the slot-based Loot All, Deposit All, Quick Stack, Restock and Sort logic, the smart-deposit rule, hotbar protection, sort types (group, count, rarity, name, id), Quick Stack to Nearby Storages with range and line-of-sight.

Changed: Fabric Transfer API replaced by vanilla Container access (double chests are one storage); one NeoForge payload instead of five; text buttons of our own beside storage screens; fixed defaults instead of per-player options.

Dropped: item favouriting, renaming and nametags, the fly-out animation, the config screens, Terrastorage's button art.
