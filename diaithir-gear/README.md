# Gléaus (diaithir-gear)

MIT, clean-room, data driven. NeoForge 26.1.2. One small module for the cross-mod gear rows.

| Row | What it does |
|---|---|
| 5 Bullet parity | Point Blank (all rights reserved, untouched) bullet hits are scaled per gun toward the Musket Mod: a hit of calibre C does `16 x sqrt(E_C / 1800 J)` (the musket ball is 16 at Age IV), reduced for fast fire by `clamp(sqrt(120 / rpm), 0.6, 1)`, so Age VII rounds beat the musket per hit without a damage-per-second jump. Table `data/diaithirgear/bullet_parity.json` (58 guns, regenerate with `tools/gen_parity.py <pointblank jar>`), override in `config/diaithirgear/bullet_parity.json`, global blend `parity.strength`. Calibre tags `diaithir:ammo/<calibre>`, `diaithir:ammo/cartridge`, `diaithir:ammo/bullets`. |
| 6 Gems | `c:gems/<stone>` now also lists the Jewelry gems; `diaithirgear:gems/socketable` is the one shared gem tag (Silent Gems, Jewelry, Iron's Jewelry). Six Apotheosis gems (`diaithirgear:peridot, garnet, opal, pearl, aquamarine, tanzanite`) give the same attribute as the Silent Gems trait of that stone at matching levels (`gem_affix_map.json`). |
| 7 Set bonuses | One bonus per family, tiers by pieces worn, applied as attribute modifiers every second, only at or above the family Age (scoreboard `age`). Families: holy (Paladins), shadow (Rogues), arcane (Wizards), all armour slots; wayfarer (Artifacts) and gemwork (Jewelry, Iron's Jewelry) count Curios items. Data `data/diaithirgear/set_bonuses/`, item tags `diaithirgear:sets/<family>`, override in `config/diaithirgear/set_bonuses`. |

| 8 Parts stations | Three benches (Smithy, Workshop Bench, Gunsmith Bench) where weapons, tools and guns are assembled from parts instead of a crafting grid. Clean-room, built from the idea of in-world part benches (Tinkers' Construct and Silent Gear are the pack's existing part mods; Tetra has no 26.1 build and is all rights reserved). See below. |

`/gearselftest` runs the checks (see TEST.md). Age gates: `age_gates.json`. Display names (five of six gems; peridot is in the retry job `gear_crossmod_names-retry`) are in `assets/diaithirgear/lang/en_us.json`, Library lines in library-sync/crossmod_gear.json, from the compute job `gear_crossmod_names` (Diaithiris via tools/archaic.py).
Tools: `tools/gen_parity.py`, `tools/gen_sets.py <silentgems jar> <pack_dump.json.gz>` (needs the pack item list and the Silent Gems jar; writes only our own data).


## Parts stations
- **Benches**: `smithy` (melee, tools), `workshop_bench` (bows, crossbows), `gunsmith_bench` (the 17 `diaithir-firearms` guns). No GUI. Sneak + empty hand picks the next blueprint (or hands the parts back when parts are on the bench). Click part items onto the bench: each fills the first open slot that accepts it. Empty hand takes the finished item. Overlay text says what is missing.
- **Parts and materials**: `data/diaithirgear/workshop/materials_base.json` (14 materials, wood to star lattice; hardness, toughness, flex 0..10, density in kg/L, colour, roles and the items or tags that count as that material). A blueprint slot has a role (head, handle, guard, binding, barrel, lock, stock...), an item count and a volume in litres, plus how much it leans on damage, durability and handling. `Craft.java` is the pure maths: score 5 is x1, 10 is x1.5, 0 is x0.5; mass is volume x density in kg; heavier than the blueprint's reference mass swings slower.
- **Age gate**: the player's Age (scoreboard `age`) must reach the blueprint's Age and every material's Age. Bench items are in `age_gates.json` (Smithy and Workshop I, Gunsmith VI).
- **Honing**: every melee hit or block broken with an assembled item is one use. Levels at 100, 300, 700, 1500 and 3100 uses give +5 % damage and +2.5 % durability each; the item is rewritten when it levels up.
- **Improvements**: hold the item, a spare improvement item in the off hand, click the bench (`improvements_base.json`: flint keen edge, iron nugget balanced, leather wrapped grip, gold nugget fine finish; each blueprint has slots).
- **Schematics**: blueprints with `"schematic": true` need the item `diaithirgear:schematic` (component `diaithirgear:schematic` = blueprint id) used on a bench once; learned ids are a player attachment kept on death. None of the shipped blueprints sets the flag yet; loot and quests hand them out.
- **Looks**: each assembled item sets `item_model` to `diaithirgear:workshop/<blueprint>`, whose model layers are one grayscale texture per slot tinted with that slot's material colour (custom model data colours). Bows and crossbows keep their vanilla look.
- **Stats on the item**: melee and tools get attack damage and speed attribute modifiers and a max durability; guns get custom data `diaithirgear: {damage_mul, spread_mul, mass_kg}` which `diaithir-firearms` reads (`Engine.crafted`).
- **Rosters**: the bench builds the 17 base guns and the 248 designs of ports #178 (gunsmith), the 168 historical melee weapons of ports #182, the 15 historical bows and crossbows of ports #203 (workshop bench, ids `ha_<id>`) (smithy, ids `hw_<id>`, same parts as the matching sword, dagger, spear or axe) and the 460 tools and kitchen items of ports #185 (smithy for metalwork, farm, mining, household, cookware and utensils; workshop bench for the rest, ids `ev_<id>`, furniture excluded). Their inputs are copied to `tools/inputs/` and `tools/gen_workshop.py` regenerates the blueprints; items that keep another mod's name show that name. Clicking a finished item's kind on an empty bench (any gun, knife...) selects its blueprint, so the long lists are quick to browse.
- **Adding items**: roster threads add a blueprint JSON (see `blueprints_arms.json`) and list it in `workshop/index.json`, or drop an array file in `config/diaithirgear/workshop/blueprints`. A blueprint whose `base` item is not installed is hidden. `tools/gen_workshop.py` writes the shipped data, `tools/gen_workshop_assets.py` the benches, textures, models, lang and gates.
- **Not done**: the visual layers are generated, not checked in a client; mining tier is not changed by head material (pickaxe and shovel keep their base tool rules); the upgrade system (`diaithir-upgrades`) has no target rule for the benches yet; hone uses from guns count only through the player-attack damage event.

## Alignment with the Foundry stations (ports #163)
Foundry's `diaithir_stations` make parts and run processes (ingots, casts, gun internals, machines); the benches here assemble finished gear from those parts, so the two chain: a Foundry station makes the `c:ingots/*` and part items, a bench here turns them into a sword, gun or pan. Ages match: Smithy and Workshop Bench I (stone, bone and clay work from the start, like the hearth bench), Gunsmith Bench VI (the assembler's Age). No code dependency, so either PR can merge first; materials read the same `c:ingots/<metal>` tags, and a Foundry recipe can output any material item listed in `workshop/materials_base.json`.
