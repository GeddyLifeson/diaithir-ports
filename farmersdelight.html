This is an unofficial NeoForge 26.1.2 port of Farmer's Delight by vectorwing. The original authors did not make it and do not support it, so please report problems with this build at https://github.com/GeddyLifeson/diaithir-ports/issues and not to them.

What changed

Finished from upstream's half-migrated 26.1 branch. Cooking pot, stove, skillet, cutting board and basket run on NeoForge's transfer API, recipes on the 26.1 Recipe API and synced to clients for JEI. Two upstream bugs fixed (dropped stacks lost all but one item; a loot modifier edited a list while iterating it). Left out: the in-pot recipe book (JEI shows every cooking recipe), the skillet's in-hand ingredient render and flip animation, hiding break cracks on canvas rugs, and the canvas background on the standing sign edit screen.
