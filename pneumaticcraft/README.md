# PneumaticCraft: Repressurized (unofficial 26.1.2 port)

This is an unofficial NeoForge 26.1.2 port of PneumaticCraft: Repressurized, made for Marlon's Diaithir pack. It is not made, endorsed or supported by the original authors. Please do not report bugs from this port to them.

Original mod: https://github.com/TeamPneumatic/pnc-repressurized (branch `26.1.2`, commit "Initial 26.1.2 branch - does not work yet!", based on the 1.21.1 release 8.2.19).
Original authors: Des Herriott (desht) and Minemaarten, with the PneumaticCraft: Repressurized contributors.

Licence: GPL-3.0 (see `LICENSE`; the API is LGPL, see `COPYING.LESSER`). Source code of this port is this directory. The original art, sounds and lang files are the original authors' work under the same licence terms as the upstream repository.

The mod id is `pneumaticcraft`. What was changed, stubbed or removed in the port is listed in `PORT_NOTES.md`. The upstream README is kept as `README.upstream.md`.

Build: `./gradlew build` with JDK 25. Part of the Diaithir modpack for NeoForge 26.1.2.
